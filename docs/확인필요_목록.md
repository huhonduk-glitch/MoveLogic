# 운동 DB 확인필요 목록

`docs/운동DB_설계표.xlsx`의 EX002~EX020(19개)은 Claude가 조사해 작성했습니다(2026-10-10).
**모두 `확인 상태 = 확인필요`** 상태이며, 개발자가 출처 링크를 확인한 뒤 확인완료로 바꿉니다.

## 1. 공통으로 확인할 것

- **출처 링크 확인**: 모든 출처는 PubMed·PMC·협회 원문/초록과 직접 대조했습니다. 단, 대부분 **초록만** 읽었습니다(본문까지 읽은 것: ACSM 2026, WHO 2020, Schoenfeld 2010, Neto 2020, JOSPT 아킬레스건 CPG 2024).
- **ACSM 2009 → 2026**: 근력운동 입장문이 2026년판(Currier 외)으로 바뀌어 새 판 기준으로 썼습니다.
- **ACSM 2011 (유산소·유연성)**: 최신판으로 바뀌었는지 확인 필요. 유연성은 초록의 "합계 60초·주 2일 이상"만 썼습니다.
- **출처 없이 쓴 칸**: 관절·움직임, 난이도, 목적 태그, 분류. 분류용이라 근거를 달지 않았습니다.
- **근거 수준 칸**: 한 칸에 하나만 쓸 수 있어 해당 행에서 가장 높은 근거로 표시했습니다.
- **재활 단계 값**: EX018 = 1(보호기), EX019·EX020 = 3(근력)으로 넣었지만 근거 없이 정한 값입니다.
- **나중 단계 칸**: 3D 근육 ID, 분석 기준각, 영상 링크, 이미지는 비워둠.
