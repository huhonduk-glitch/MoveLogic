## 지금 단계 안내

무브로직은 "운동을 시키는 앱"이 아니라 **왜 하는지 보여 주고 이해시키는 운동 가이드**를 목표로 만들고 있어요. 지금은 개발 중이라 화면 틀(홈 · 운동 목록 · 운동 상세 · 내 루틴)이 먼저 만들어져 있고, 운동은 **근거 출처 확인을 마친 것부터** 차례로 올라와요.

## 화면 구성

아래 메뉴는 세 칸이에요.

| 메뉴 | 하는 일 |
| --- | --- |
| 🏠 홈 | 운동 둘러보기, 내 루틴으로 가는 입구 |
| 💪 운동 | 공개된 운동 목록 |
| 📋 내 루틴 | 내가 고른 운동 모아 보기 |

![홈 화면](images/manual-01.png)

## 운동 목록

공개된 운동이 카드로 보여요. 아직 공개된 운동이 없으면 「근거 확인을 마친 운동부터 차례로 올라와요」 안내가 나와요.

![운동 목록](images/manual-02.png)

## 운동 상세

운동을 누르면 아래 순서로 설명이 나와요.

1. **해부학**: 주동근(주로 쓰는 근육), 협응근 · 안정근, 관절과 움직임
2. **역학**: 역학 포인트, 흔한 오류
3. **설명 · 가이드**: 수행 방법, **왜 하는가**, 운동 기준(FITT: 빈도 · 강도 · 시간 · 종류), 쉬운 버전 · 어려운 버전
4. **안전**: 대상 부위, 회복 단계(1단계 보호기 → 2단계 가동범위 → 3단계 근력 → 4단계 기능 · 복귀), 금기 · 주의

모든 설명에는 근거 출처가 붙어요.

![운동 상세 · 해부학](images/manual-03.png)

![운동 상세 · 왜 하는가와 안전](images/manual-04.png)

## 내 루틴

운동 상세에서 고른 운동이 **내 루틴**에 모여요. 아직 고른 운동이 없으면 「아직 루틴이 없어요」가 보여요.

![내 루틴](images/manual-05.png)

## 앞으로 생길 기능 (계획)

- 목적 · 상태를 넣으면 맞춤 루틴과 "왜 이 운동인가" 설명
- 3D 근육 모델에 쓰는 근육 색칠하기
- 재활 모드(손상 부위 표시 → 단계별 회복 운동)
- 영양 · 생리학 정보 카드

## 자주 묻는 질문
